# SketchUp 工作流套件

一套面向 **SketchUp Pro 2020+** 的完整建模工作流,覆盖从项目准备到交付归档的全过程。默认按**建筑方案 / 室内设计**方向编写,景观、展陈、木工方向可按各篇末尾的说明裁剪。

它由三部分组成:

1. **一套模板做法** —— 单位、标记、场景、样式一次做好,以后每个项目直接用(见 01)
2. **一套操作规范** —— 建模、组织、材质、出图各阶段的标准动作和避坑清单(见 02~08)
3. **一组自动化脚本** —— 清理、体检、批量出图等重复劳动,一键完成(见 scripts/)

## 一句话流程

```
准备模板 → 导入底图 → 体量建模 → 组件细化 → 材质深化 → 场景与风格 → 出图/渲染 → 交付归档
```

## 快速上手(约 40 分钟)

1. **做模板(一次性,约 20 分钟)**:新建空白文件,照着 `01-准备与模板` 走一遍,最后运行脚本"01 初始化标准模板",再 `文件 > 另存为模板`。
2. **装脚本(约 5 分钟)**:把 `scripts/` 下 4 个 `.rb` 文件放进插件目录(或临时粘贴到 Ruby 控制台),方法见 [scripts/README-脚本使用说明.md](scripts/README-脚本使用说明.md)。
3. **开新项目(约 5 分钟)**:按 `08-文件管理与协作` 的文件夹结构建目录,导入底图。
4. **建模**:对照 `02`、`03` 的规范和清单;文件变大就跑一次"03 模型体检报告"。
5. **出图/交付**:按 `05` 建场景出图;交文件前跑"02 一键清理模型"。

## 四张检查清单(全文贴在下面各篇里,这里汇总)

**建模前**
- [ ] 用的是自己的模板(单位、标记、场景齐全)
- [ ] 底图已核对单位并锁定
- [ ] 项目文件夹按 08 的结构建好

**建模中(随时自查)**
- [ ] 推拉之前先成组/成组件
- [ ] 没有游离在组外的散线散面
- [ ] 组件有命名,内容有归标记
- [ ] 文件超过 50MB 或面数超过 50 万 → 跑体检报告

**出图前**
- [ ] 跑过"一键清理模型"并另存
- [ ] 场景属性(相机/样式/标记/阴影/剖切面)勾选完整
- [ ] 立面场景=平行投影,透视场景=两点透视

**交付前**
- [ ] 版本号已更新(如 `_v03`)
- [ ] 清理未使用项,文件大小正常
- [ ] 需要的成果已导出 PDF / PNG / DWG
